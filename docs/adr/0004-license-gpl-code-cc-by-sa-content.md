# License: GPL-3.0 code, CC BY-SA 4.0 content

The project aims to be open source, with no revenue ambition. We separate **code** and **content**: the code is under **GPL-3.0** (copyleft — a fork must stay open, nobody can close the game), the content (assets and Maps) under **CC BY-SA 4.0** (attribution + share-alike). A **hub charter** — terms of use, not a licence — states that published Maps remain free and open, and allows their removal if placed behind a paywall.

## Considered and rejected

- **CC BY-NC-SA 4.0** for content: would forbid selling, but the content would no longer be "open source" in the OSI sense, and it conflicts with the broad licence Valve grants itself on the Steam Workshop.
- **Permissive (MIT / CC BY)**: would leave derivatives closed; copyleft is preferred.

## Consequences

"Open source" applies to the **code**; the content is "free, share-alike". Selling is **not** technically prevented: the hub charter is the only safeguard, and it only binds the hub.
