# Licence : code GPL-3.0, contenu CC BY-SA 4.0

Le projet se veut open source, sans ambition de revenu. On sépare **code** et **contenu** : le code est sous **GPL-3.0** (copyleft — un fork doit rester ouvert, personne ne peut refermer le jeu), le contenu (assets et cartes) sous **CC BY-SA 4.0** (attribution + partage à l'identique). Une **charte du hub** — des conditions d'utilisation, pas une licence — déclare que les cartes publiées restent libres et gratuites, et autorise leur retrait si elles sont mises derrière un péage.

## Options considérées et écartées

- **CC BY-NC-SA 4.0** pour le contenu : interdirait la vente, mais le contenu ne serait plus « open source » au sens OSI, et cela frotte avec la licence large que Valve s'octroie sur le Steam Workshop.
- **Permissif (MIT / CC BY)** : laisserait refermer des dérivés ; le copyleft est préféré.

## Conséquences

« Open source » vaut pour le **code** ; le contenu est « libre, partage à l'identique ». La vente n'est **pas** techniquement empêchée : la charte du hub est le seul garde-fou, et elle ne lie que le hub.
