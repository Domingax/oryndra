# Progression: every move available from the start

Mirror's Edge Catalyst *gates* its moves behind an unlock tree (Runner Kit). oryndra does the opposite: a competitive game must be fair, so **every move is available from the first run**. Progression rewards **mastery** — medals per Course by time, records, Ghosts — and not unlocking abilities.

## Considered and rejected

- **Unlock tree (Runner Kit-like)**: delays access to the competitive game and creates inequality between players.

## Consequences

No "move-set progression" to design; the Training Map (tutorial) teaches the moves but does not unlock them.
