# Co-op: teamplay through dedicated mechanics, not a parallel race

oryndra's co-op is not about several players running the same route. It rests on **dedicated mechanics** where players help each other clear obstacles **impossible alone** (leg-up, pull-up assist, counterweight, relay…). Every mechanic must be **reciprocal** — the helper must be able to progress in turn, otherwise a player is left stuck — and Courses that depend on it are **flagged as co-op**.

## Considered and rejected

- **"Parallel" co-op** (each runs their own route, Ghosts visible): useful, but it is asynchronous multiplayer, not co-op; it can exist *in addition*, never *instead*.

## Consequences

Level design has two levels (solo / co-op); synchronising assists requires netcode; co-op arrives **after** the full move set and procedural generation.
